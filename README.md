# FPMini

Неофициальный клиент FunPay для Android. Бесплатный, без рекламы, с открытым кодом (MIT).
Не связан с FunPay; оплата и покупка проходят на сайте funpay.com.

## Что умеет

Неофициальный бесплатный клиент для **продавцов** FunPay. Пять вкладок:

- **Чаты** — список диалогов и переписка, шаблоны ответов, автообновление.
- **Мой профиль** — баланс, активные продажи, рейтинг, все ваши лоты по разделам, поднятие одной кнопкой.
- **Мои продажи** — заказы с фильтром (оплачены / закрыты / возвраты), сумма к выполнению, переход в чат с покупателем.
- **Поддержка** — заявки в support.funpay.com, переписка и ответ в заявку.
- **Автоматизация** — работа в фоне (постоянное уведомление, отключается), автоподнятие лотов, приветствие и ответы по ключевым словам, уведомления о сообщениях и заказах, журнал событий.

Темы: системная / светлая / тёмная, AMOLED, акцентный цвет, скругление, размер текста.
Вход — на настоящей странице funpay.com или по golden_key. Ключ хранится только на телефоне.

## Как получить APK

1. Создайте репозиторий на GitHub и загрузите туда эту папку.
2. GitHub Actions соберёт APK сам (вкладка **Actions** → последняя сборка → артефакт `fpmini-apk`).
3. Для релиза со ссылкой на скачивание: создайте тег `v0.1.0` — APK появится в **Releases**.

### Свой ключ подписи (рекомендуется)

Без него APK подписывается отладочным ключом, который на каждой сборке разный — новую версию придётся ставить, удалив старую.
Один раз создайте ключ и добавьте секреты в **Settings → Secrets and variables → Actions**:

```
keytool -genkeypair -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias fpmini
base64 -w0 release.jks   # → секрет KEYSTORE_BASE64
```

Секреты: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`fpmini`), `KEY_PASSWORD`.
Сам файл `release.jks` в репозиторий не кладите.

## Структура

- `core/` — разбор страниц FunPay (чистый Kotlin + Jsoup). `core/src/test/.../ParserCheck.kt` — проверка на образцах разметки.
- `app/` — приложение на Jetpack Compose: `data/` (сеть, куки, настройки), `ui/` (экраны и компоненты), `ui/theme/` (темы).

Если FunPay поменяет разметку и какое-то поле перестанет показываться — правится в `core/.../Parser.kt`.
